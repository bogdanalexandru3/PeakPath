# AI Log - Etapa 1

## Context
Acest fișier consemnează utilizarea asistenței AI pentru realizarea primei etape a proiectului PeakPath.

## Interacțiune 1
- Prompt: "Ajută-mă să creez o pagină statică pentru un jurnal de trasee montane, cu antet, formular cu câmp text și listă fixă de 3 carduri."
- Răspuns folosit: structură HTML pentru antet, formular și secțiune de liste; stilizare pentru layout cu două coloane și dark mode.

## Interacțiune 2
- Prompt: "Verifică dacă designul respectă cerințele accesibilității: focus vizibil, contrast și layout responsive."
- Răspuns folosit: reguli CSS pentru focus, culori variabile și media query sub 700px.

## Concluzie
AI-ul a fost folosit pentru structurarea inițială a designului și pentru validarea rapidă a accesibilității și responsivității paginii.
